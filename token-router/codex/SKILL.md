# Codex token-router

위치: D:/Codex/_Skills/token-router.
도구: python D:/Codex/_Skills/token-router/scripts/router.py <command>.

## 작업 방식
- 큰 작업은 검증 가능한 단위로 나눈다. 간단한 요청에 계획표나 라우터 호출을 추가하지 않는다.
- rg로 범위를 좁혀 필요한 구간만 읽는다. 독립 조회는 묶고 긴 출력은 파일로 저장한다. 이미 확인한 내용은 필요할 때만 다시 읽는다.
- 대용량 데이터는 스크립트로 처리하고 구조·집계·검증 요약만 대화에 남긴다. 재사용할 스크립트를 저장한다.
- 토큰 절약 때문에 필수 검증이나 승인된 작업을 생략하지 않는다.

## 모델 추천
필요할 때 route "작업 설명"을 실행한다. 규칙 기반 추천이며 가격 비교나 자동 전환이 아니다.
config.json의 모델은 작성 세션에서 제공된 모델이다. 현재 환경의 사용 가능 여부를 확인하고 없으면 현재 모델을 유지한다. 사용자 모델·effort 선택을 우선한다.
서브에이전트는 사용자가 병렬 작업을 요청했고 독립적인 작업이 있을 때만 사용한다. 절약 효과를 보장하지 않는다.
현재 대화의 모델을 변경했다고 주장하지 않는다. 다음 세션이나 허용된 서브에이전트 설정으로 추천한다.

## 세션과 인수인계
check는 사용량을 모르면 unknown을 반환한다. 실제 컨텍스트 사용량을 제공받았을 때만 check --context-tokens N을 쓴다. 누적 과금 토큰과 컨텍스트 크기를 혼동하지 않는다.
80k/200k는 설정 가능한 검토 기준이지 모델 한도가 아니다. 매 답변에 토큰 수나 세션 꼬리말을 강제하지 않는다.
사용자가 세션 분리를 요청하거나 압축으로 핵심 결정이 유실될 우려가 있거나 큰 단계가 끝날 때 인수인계를 남긴다.

1. 수정 파일이 있다면 snapshot --project "프로젝트 경로" --files "상대경로1" "상대경로2"로 이번 작업 파일을 백업한다. 전체 폴더를 복사하지 않는다.
2. handoff --project "프로젝트 경로"로 파일을 생성한다. 프로젝트가 없으면 D:/Codex/handoff를 사용한다.
3. 생성된 양식의 모든 항목을 실제 정보로 채운다. 깨진 테스트, 진행 중 프로세스, 백업 경로와 제외 내역을 적는다. 원본 내용 대신 필요한 경로를 적는다.
4. 인수인계 링크를 제공하고 승인된 작업을 계속한다. 새 대화에서는 사용자가 지정한 인수인계를 읽고 미완료·주의부터 처리한다.

journal --project "경로" --message "검증된 작업 요약"은 단계 완료 시 선택적으로 사용한다. 비밀이나 요청 원문을 복사하지 않는다.
## 자동 입력 분석과 확장
scripts/hook.py가 UserPromptSubmit에서 작업을 분류하고 실제 현재 모델과 비교한다. 불일치 시 입력을 차단하고 변경 안내를 표시한다. 사용자는 모델을 바꿔 다시 보내거나 [router-continue] 접두어로 현재 설정을 유지할 수 있다.
SessionStart, Stop, PreCompact는 확장용 세션 상태와 마지막 입력 토큰을 갱신한다. 상태 파일은 ~/.codex/token-router/sessions에 있으며 요청 원문은 저장하지 않는다.
현재 effort는 훅 입력 또는 같은 turn_id의 transcript 값이 확인될 때만 비교한다. 확인되지 않은 값은 추정하지 않는다.
기존 Token Router Indicator 확장은 이 상태를 읽어 Codex 카드·상태 표시줄·차단 알림을 표시한다. 훅이 실행되기 전에는 데이터 대기로 표시한다.
Codex는 새 훅을 사용자 신뢰 처리 전까지 실행하지 않는다. 재시작 후 /hooks 또는 클라이언트의 훅 검토 UI에서 등록된 정의를 확인한다. 신뢰 저장소를 직접 수정하거나 보안 검토를 우회하지 않는다.
자동 모델 전환이나 새 세션 생성은 하지 않는다.
백업은 .handoff/backups에 gzip으로 저장한다. 삭제 파일은 manifest에만 기록한다. 파일명 제외는 완전한 비밀 탐지가 아니므로 대상을 검토한다. 자동 삭제·복원은 하지 않는다.
